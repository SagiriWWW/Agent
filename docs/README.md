# 项目文档目录

本目录集中存放当前 Agent 工具箱 MVP 的说明文档、项目原始材料和阶段记录。

## 目录说明

- `MVP验收说明.md`：当前 MVP 的目标、验收范围、运行方式和后续计划。
- `当前项目计划_对话交接版.md`：面向新对话/协作者的当前实际计划，说明已实现能力、未实现蓝图和后续路线。
- `rule_reviews/`：规则库版本验证、专家复核包和规则采纳建议。
- `design/`：与当前 Agent MVP 方案直接相关的设计文档。
- `source_materials/root/`：原本散落在项目根目录下的项目书、申请书等原始材料。
- `source_materials/related/`：原 `相关文档/` 中保留的项目资料。
- `work_records/`：阶段性工作记录、阶段报告和对应源文件。

项目运行所需的稳定配置仍保留在根目录 `configs/`，例如 `configs/telemetry_schema.yaml` 字段展示配置和 `configs/schema_semantics.yaml` 语义角色/别名配置；这里的 `docs/` 只存放说明材料和阶段记录。

## 归档原则

- 项目代码、测试、示例规则和数据集保留在根目录的一线工作区。
- 项目申请书、计划书、设计方案、阶段记录统一放入 `docs/`。
- 运行产物、缓存文件、系统临时文件不归档，重新运行项目会自动生成。
- 疑似密钥导出、临时实验目录和无关样例不进入文档归档。
